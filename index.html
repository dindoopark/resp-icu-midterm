한눈에 보기
  • 천식 '중요 표시' 7장: 진단(FEV1/FVC <0.75–0.80, BD 반응 >12% 그리고 >200 mL), 검사 전 중단 4·24·36h, 1안·2안, 졸림·혼미·호흡음 감소 → 즉시 SABA+산소·ICU
  • ICS: 천식 최우선 약(LABA·SABA를 ICS 없이 X, 단 급성악화 첫 약 = SABA) / 흡입 전 끝까지 내쉬기, ICS 후 헹구고 뱉기(구강 칸디다증·쉰 목소리 예방)
  • COPD: BD 후 FEV1/FVC <0.70, 지난 1년 악화력 고/저위험, LABA+LAMA 1차 → 고위험 + 호산구 ≥300 = 3제, 급성악화 SpO2 88–92%
  • ARDS: 2024 정의 3범주, 사망률↓ 입증 = 저VT 6 mL/kg PBW·Pplat ≤30 + 복와위, 장시간 RM·HFOV = 하지 마라
  • NMBA: 발생 48h 이내 + P/F ≤100, 가능하면 최대 48h, cisatracurium 1선 / 스테로이드 = 조건부·근거 중등도
  • 구조와 기능: VC = IRV+VT+ERV(4800/3400), TLC = VC+RV(6000/4500), 분압 100/40·40/45, CO2 7·23·70%
  • 네뷸라이저: β2 작용제 → 항콜린제 → (객담 많으면) NAC → 석션 → ICS. NAC 처음 금지(역설적 기관지 경련)

1. 약물

  • 🎯 호흡곤란 → 유발 요인부터 빨리 판단 → 수축·염증 = 기관지확장제·ICS / 객담 = 거담제·객담용해제 / 기침 = 진해제
  • 🎯 흡입기 = 사용법 교육 + 매일 쓰는 순응도 / 흡입 전 숨 끝까지 내쉬기(가장 많이 빠뜨림)
  • 🎯 ICS 후 헹구고 뱉기(삼키면 전신 흡수↑) / 대표 부작용 = 구강 칸디다증 + 쉰 목소리
  • 🎯 거담제·객담용해제는 가래를 꺼내 주지 못함 → 기침·석션·체위배액·두드리기
  • 🎯 ARDS 이뇨제: 투과성↑면 폐부종이 있어도 순환 혈액량은 부족할 수 있음(체액 과다로 단정 X) → 승압제 요구↑ = 이뇨 보류, 관류 먼저
  • 🎯 NMBA 가능하면 최대 48h, 호전되면 조기 중단 / Hofmann 약물 = 체온·산염기 유지(저체온·산증 → 느림, 고열·알칼리증 → 빠름)
  • ★ β2 작용제: 빈맥·부정맥·고혈당 → 심부정맥·저칼륨혈증·조절 안 되는 당뇨 주의(천식 p.23은 부작용) / 항콜린제: 구강건조·요저류·안압↑ → 녹내장·전립선 비대 주의
  • ★ SABA·SAMA = reliever(5~10분) / LABA·LAMA = controller(매일). Ventolin·Atrovent 둘 다 속효성
  • ★ guaifenesin = 수분↑ / NAC = S–S 결합 파괴 / ambroxol = 표면활성제↑·섬모 활성화
  • ★ 스테로이드 = PLA2 억제(NSAID = COX). ICS는 직접 확장 X → 기관지확장제와 함께
  • ★ cisatracurium(Hofmann, 간·신부전에도 축적 없음) 1선 / vecuronium = 간·신 / atracurium = 히스타민 방출

2. 구조와 기능

  • 🎯 pharynx = 인두("파인"), larynx = 후두
  • 🎯 흡기 = 흉쇄유돌근·외늑간근 수축 + 횡격막 수축 → 압력↓ → Po > Pi / 호기 = 내늑간근·복직근 + 횡격막 이완 → Po < Pi / 휴식기 Po = Pi
  • ★ 안정 호기 = 수동적, 호기근은 강제호흡 때. DRG = 매 주기(흡기 2초·호기 3초) / VRG = 강제호흡만
  • ★ 전도부 끝 = 종말세기관지 / 호흡부 시작 = 호흡세기관지. 세기관지 약 1 mm, 연골 없음
  • ★ 호흡막 = 편평상피 + 내피 + 융합된 기저막 3층, 0.5 µm, O2·CO2 지용성(surfactant는 3층 아님)
  • ★ 과립폐포세포 → surfactant / 먼지세포 = 폐포대식세포 / 순응도: 폐기종↑ · RDS↓
  • ★ VC 남 4800/여 3400, TLC 남 6000/여 4500(4200 아님), 해부학적 사강 약 150 mL
  • ★ 분압(PO2/PCO2): 동맥 쪽 100/40, 정맥·조직 쪽 40/45, 조직 도착 동맥혈 PO2 95
  • ★ O2: 혈장 1.5%, 나머지 헴의 Fe. 결합 결정요인 = PO2·pH·온도(운동: 온도↑·pH↓·PO2↓ → O2 공급↑)
  • ★ CO2: 혈장 7 · Hb(globin) 23 · 중탄산 70%, 염소이동
  • ★ 화학수용기 = PCO2에 더 민감, 연수 = CSF pH·PCO2(PO2 X) / 동(sinus) = 압력, 체(body) = 화학
  • ★ 이물질 → 우측 주기관지(굵고 수직) / 흉막 = 장막

3. COPD

  • 🎯 국내 특징 = 결핵(비흡연 COPD 최중요 인자) / 문진은 과거 흡연력까지

  • ATS: 초기 중증 ARDS에서 NMBA 사용을 제안한다 — 조건부 권고 / 낮은 근거(스테로이드 = 중등도보다 낮음)
  • 초기 중증 = 발생 48시간 이내 + P/F ≤100 mmHg
  • 대상: 이미 깊은 진정이 필요한 환자, 또는 환기 설정·진정 조절에도 심한 비동시성·임상 악화가 지속되는 환자
  • 기간: 가능하면 최대 48시간, 빨리 호전되면 조기 중단(근육 소실·신경 손상 예방)
  • 결과: 깊은 진정 대조군 대비 사망률 RR 0.72(감소), 얕은 진정 대조군 대비 RR 0.99(감소 없음; 진정 깊이와 NMBA 조건이 섞여 해석 불확실). [보충] 깊은/얕은 진정 대조군 = ARDS p.80의 이전 RCT 3개/ROSE. 압력손상은 감소(RR 0.55), ICU 획득 쇠약(ICU-AW)은 증가 가능성, 불확실(RR 1.16).

🎯 교수 강조 (9/14 00:59:03) 초기 중증 ARDS에서 NMBA는 가능하면 최대 48시간 이내로 쓰고, 빨리 호전되면 일찍 끊는다. ATS 권고에서 가장 중요한 부분이다 — "가능하면 최대 48시간 이내에 해야 된다 … 권고사항의 그게 가장 중요한 파트"

⚠️ 헷갈림 주의 48시간이 두 번 나온다: '발생 48시간 이내'(초기의 정의) vs '사용 최대 48시간'(기간). 원 연구들은 P/F 150 미만으로 등록했지만 [보충] 시험은 슬라이드 ≤100 기준. ARDS p.82: 48시간은 절대 상한 아님(넘기면 12시간마다 재평가, P/F >150이면 중단).

5-4. NMBA 기전과 3종 비교 (p.24~25) ★

  • 기전: 운동신경 말단 ACh → 골격근 니코틴 수용체(Nm) → 수축. NMBA가 ACh와 경쟁해 Nm 차단 → 횡격막 포함 근육 이완 → 인공호흡기가 계획대로 보조, 과도한 압력·과팽창 손상 방지 (p.24)
약물 대사 경로 특징 (p.25)
cisatracurium Hofmann 제거(체온·생리적 pH에서 혈중 자발 분해) 간·신부전에도 축적 없음 → 1선 표준(교수: 중환자 대부분 다발성 장기부전)
vecuronium 간 대사 + 신장 배설 간·신부전 시 반감기 연장·작용 지연
atracurium Hofmann 제거 + 혈장 에스테라제 축적 위험 낮음, 용량 의존 히스타민 방출(기관지 연축·저혈압·홍조)
  • 체온·산염기 감시: 저체온·심한 산증 → 분해 지연, 고열·알칼리증 → 너무 빨리 분해 (p.25)
  • ARDS p.82: 비스테로이드계라 ICU-AW↓, vecuronium보다 MV·ICU 기간↓(노트). 「국내 미보유」(ARDS 교수)는 미확인

🎯 교수 강조 (9/14 01:06:22) Hofmann 제거 약물(cisatracurium·atracurium)을 쓸 때는 체온과 산염기 균형을 잘 유지해야 비동시성을 빨리 줄이고 효과를 높일 수 있다 — "산염기 불균형을 잘 유지하면서 … 효과적으로 이 약물을 쓰는 게 중요하다"

💡 암기 팁 Hofmann은 "따뜻하고 약알칼리"에서 일한다: 차갑고 산성이면 느려지고, 뜨겁고 알칼리면 빨라진다.

⚠️ 헷갈림 주의 항콜린 기관지확장제의 표적 = 무스카린(M) 수용체 / NMBA의 표적 = 골격근 니코틴(Nm) 수용체.

  • ARDS 강의(p.21·26 노트·35): 소생 목표 달성 후 보존적 수액·이뇨가 예후 개선(FACTT) = 위 표 2·3단계 → 1단계 이뇨 보류와 충돌 아님
  • 패혈증·패혈성 쇼크 초기 소생: IV 결정질 최대 30 mL/kg 제안(조건부), 수액 반응성(심박출량↑ 여부)을 보며 추가, 혈역학 감시로 개별화 (p.28)

1. 호흡기계 구조

1-1. 전도부 vs 호흡부 ★

구분 범위 기능
전도부(conducting portion) 코·인두·후두·기관·기관지·세기관지 – 종말세기관지 공기 운반 + 여과(전사 추정)·가온·가습 → 이물질·병원체 대부분을 폐포 전에 제거

  • 교수가 든 호흡기계 기능 5가지(슬라이드 없음): 기체교환 · 공기를 기체교환면으로 들이고 내보냄 · 기체교환면 보호(탈수·온도 변화·병원체) · 발성 · 후각

1-2. 점액섬모 청소 ★

  • 호흡점막 = 호흡상피(섬모원주상피 + 술잔세포 goblet cell = 약물 강의 배상세포) + 고유판(lamina propria, 점액샘 발달) (p.4)
  • 흐름: 술잔세포·점액샘이 점액 분비 → 점액이 미생물과 결합 → 섬모(cilia) 운동으로 한 방향(위, 인두 쪽) 운반 → 침·음식과 함께 삼킴 → 위산·소화효소로 분해 (p.4, 그림으로 약 3분 반복)

1-3. 코·인두 ★

  • 코(p.5): 코안뜰(nasal vestibule) = 뻣뻣한 털로 이물질 차단 / 경구개(hard palate) = 코안의 바닥(입에서 보면 천장) / 연구개(soft palate) = 근육. 형광: 비갑개·코안뜰·바깥콧구멍·경구개·연구개
  • 인두(pharynx, p.6) = 소화계통과 호흡계통의 공유 공간, 뒤콧구멍(choana) – 후두·식도 입구

인두 3구분 범위(교수 설명) 특징
비인두(nasopharynx) 뒤콧구멍 – 연구개 끝 전형적 호흡상피

1-4. 후두(larynx) ★

  • 공기는 성문(glottis)으로 들어온다. 인대로 연결된 연골 9개 + 골격근 (p.7)
구조 핵심
후두덮개(epiglottis) 성문 위를 덮음. 삼킬 때 후두가 위로 당겨지며 성문을 막아 음식물이 기도로 못 들어감. 삽관 때 자주 듣는 구조

1-5. 기관·기관지 ★

  • 기관(trachea, p.8): 반지연골에 이어져 시작(제6경추 C6 높이), 지름 약 2.5 cm·길이 약 11 cm, C자 연골 15–20개(수치는 교수 추가)
  • C자 연골은 앞이 닫히고 뒤가 열림 → 연골 없는 뒷벽(탄력인대 + 민무늬근 = 기관근 trachealis)이 식도와 맞닿아 큰 음식물이 내려갈 때 공간을 내준다. 연골은 압력이 변해도 기관 모양을 유지
  • 기관근은 자율신경 지배, 교감신경 흥분 → 기관 지름↑ (p.8)

📝 교수 추가 (00:17:08) 천식·COPD 환자에게 쓰는 네뷸라이저 벤토린(Ventolin)은 β2 agonist(= β2 작용제, SABA; 교감신경 작용) → 기관·기관지 민무늬근 이완 → 기도 확장. [보충] 성분명은 살부타몰(salbutamol).

  • carina: 기관이 좌·우 1차 기관지(primary = main bronchus)로 갈리는 곳 = 삽관 튜브 위치 확인 기준점(교수)
  • 우측 1차 기관지는 좌측보다 굵고 수직에 가까움 → 기관에 들어간 이물질은 우측으로 갈 확률이 높다(교수, 슬라이드 없음)

1-6. 세기관지 – 폐포 ★

구조 핵심
세기관지(bronchiole) 지름 약 1 mm, 연골 없음, 자율신경 지배 민무늬근 많음 → 지름으로 공기 유속·방향 조절 (p.9)
종말세기관지(terminal bronchiole) ★ 전도부의 마지막. 하나가 폐소엽(pulmonary lobule = 결합조직 중격으로 구분된 폐조직의 단위 구조) 하나에 공기 공급. 지름 0.3–0.5 mm(교수)
호흡세기관지(respiratory bronchiole) ★ 종말세기관지가 폐소엽 안에서 갈라진 것, 기체교환면으로 공기 운반 (p.11)
폐포관 → 폐포주머니 → 폐포 ★ 형광 강조 (p.11). 폐포는 한쪽 약 1억 5천만 개, 양쪽 표면적 약 140 m²(테니스코트 절반, 교수)
세기관지 민무늬근 교감신경 흥분 부교감신경 흥분
반응 이완 → 기도 확장 수축 → 기도 좁아짐

2-2. 압력차와 호흡근 ★

  • 교수가 화면에 직접 쓴 원리: 공기는 압력 높은 곳 → 낮은 곳(pressure gradient). 폐가 팽창하면 폐 안 압력↓, 쪼그라들면 압력↑ (p.18)
  • 슬라이드: 흉강 압력(thoracic cavity pressure)을 바꾸는 주체 = 횡격막(diaphragm)·늑골(rib) (p.18). 폐 부피는 흉강 부피가 정한다(교수 표현은 "흉막강")

2-3. 순응도(compliance)

  • 폐의 탄력성·팽창능력. 낮을수록 공기를 넣고 빼는 데 에너지↑ (p.20). 평소 호흡근 에너지 = 기초 에너지의 3–5% → 순응도가 낮으면 숨쉬기만으로 지칠 만큼 늘어난다
  • 교수 예시(슬라이드 없음, 00:43:07): 폐기종(emphysema) = 순응도↑(폐포 지지조직 파괴) / RDS = 순응도↓(surfactant 부족) / 늑골·척추 관절염 = 순응도↓(전사 복원 추정). 국문으로 유순도라고도 한다(천식·COPD·약물 강의의 "순응도"는 복약·흡입기 adherence로 뜻이 다르다 → 폐 compliance는 ARDS 강의처럼 "유순도"로 읽는다)

⚠️ 헷갈림 주의 순응도가 높다고 정상은 아니다(폐기종). [보충] 엄밀히 compliance = 팽창능력(ΔV/ΔP)이고 탄력(elastance)은 그 역수다. 정의 문항은 슬라이드 표현 "탄력성, 팽창능력"을 맞는 진술로 본다.

⚠️ 강의 간 주의 ① COPD 강의(p.4·10)의 "폐기종 → 탄성 감소"는 탄성 반동(elastic recoil)↓ = 순응도↑와 같은 현상이다. "폐기종에서 탄력성↑/↓"처럼 방향만 따로 물으면 팽창능력↑ = 탄성(반동)↓로 풀어 판단한다. ② 여기 RDS는 surfactant 결핍형(미숙아 RDS 모델)이다. 성인 ARDS(10/19)는 surfactant 고갈도 기전에 들지만 유순도↓의 직접 원인을 환기되는 폐 용적↓(baby lung = 작은 폐, 남은 폐 유순도는 거의 정상)로 보고, 외부 surfactant 투여는 실패했다.

3-2. 산소 운반 ★

  • 큰 그림: O2는 대부분 혈색소(Hb) 결합, CO2는 세 형태(탄산(중탄산)·Hb 결합·혈장 용해). 둘 다 혈장에는 조금만 녹아 대부분 적혈구가 운반한다
  • 동맥혈 O2의 약 1.5%만 혈장 용해, 나머지는 Hb 중앙의 Fe에 결합(교수: 정확히는 헴(heme)의 철). Hb + O2 ↔ HbO2 가역 (p.23)
  • Hb의 O2 결합량 결정요인 = PO2 · pH · 온도 (녹화에서 세 번 반복)
  • 조직 PO2가 낮을수록 O2가 많이 떨어져 나온다(교수 수치, 슬라이드 없음, 00:56:02): 비활성 조직(PO2 약 40) → 결합 O2의 약 25% 유리 / 활성 조직(PO2 약 15–20) → 약 80% 유리 → 약 3배 공급 (운동 중 골격근은 80·90%까지)
  • 골격근 수축(운동) 시: 온도↑ · 국소 pH↓ · PO2↓ → Hb의 O2 결합↓ → 골격근에 O2 충분히 공급 (p.23). 교수: 활성이 늘어 산이 생기고 pH가 낮아지면 이를 "활성 증가" 신호로 받아 O2가 떨어져 나오며, 온도↑도 같은 방향

📝 보충 이 방향이 산소해리곡선 우측이동(pH↓·PCO2↑·온도↑·2,3-DPG↑)이다. 녹화가 이 설명 도중(00:58:15) 끊겨 교수가 해리곡선·Bohr 효과를 말했는지는 확인할 수 없고, 슬라이드에도 이 용어는 없다.

  • 그림 흐름: CO2의 93%가 적혈구 안으로 → 탄산탈수효소(carbonic anhydrase)가 H2CO3로 → H+와 HCO3−로 해리 → H+는 완충제, 특히 Hb가 제거 / HCO3−는 Cl−와 맞바꿔 혈장으로 = 염소이동(chloride shift). 폐에서는 거꾸로 진행해 CO2를 내보낸다 (p.23–24)
  • 슬라이드 문장은 "혈장 안에서 bicarbonate 이온으로 변환되어 운반"이지만 같은 쪽 그림은 변환은 적혈구 안(탄산탈수효소), 운반은 혈장(chloride shift) 이다. 기전은 그림 기준으로 이해하되, 슬라이드 문장 그대로(혈장에서 bicarbonate 이온 형태로 운반) 나오면 맞는 진술로 본다

💡 암기 팁 혈장 7 · Hb 23 · 탄산(중탄산) 70. O2는 Hb의 Fe, CO2는 globin에 붙어 자리가 달라 동시 운반이 된다(슬라이드 기준 답). [보충] Hb가 O2와 결합하면 CO2 운반력이 줄어드는 Haldane 효과는 별개 현상이다(COPD 강의에서 고농도 산소 CO2 저류 기전으로 언급, 출제 안 함).

4-3. 반사 조절

  • 신장수용기(stretch receptor, 기계수용기): 팽창반사(inflation reflex) = 강제호흡 시 폐의 과다팽창을 막음. 팽창·수축반사 모두 안정호흡 때는 일어나지 않고 강제 흡기·호기에서 중요 (p.31)

⚠️ 헷갈림 주의 수축반사(deflation reflex)를 슬라이드는 "폐가 수축할 때 흡기중추 억제, 호기중추 자극"으로 적었다. [보충] 교과서는 반대(흡기 자극, 폐 허탈 방지). 시험은 슬라이드 기준이지만 상충 구간이라 이 문장으로는 연습문제를 내지 않는다.

  • 압력수용기(baroreceptor, 기계수용기) (p.32): 압력 변화를 감지해 자율신경계통 기능 조절. 대동맥동(aortic sinus)·경동맥동(carotid sinus) = 혈압 → 순환·호흡중추 / 폐 = 팽창 정도 → 호흡리듬중추 → 호흡수 조절
  • 화학수용기(chemoreceptor, = 약물 강의 화학수용체) ★ (p.33): 혈액·CSF의 화학조성 변화 → 호흡수·깊이 조절
화학수용기 대동맥체(aortic body)·경동맥체(carotid body) [보충: 말초] 연수(medulla oblongata) [보충: 중추]
감지 동맥혈 pH · PCO2 · PO2 CSF의 pH · PCO2 (PO2 없음)
  • PO2보다 PCO2에 더 민감 ★: 동맥혈 PCO2가 조금만 변해도 CO2 수용기가 자극되지만, 산소수용기를 자극할 만큼 PO2가 떨어지는 일은 거의 없다 (p.33)

💡 암기 팁 동(sinus) = 압력, 체(body) = 화학 (p.32–33). 연수는 O2를 못 보므로 PO2를 감지하는 것은 대동맥체·경동맥체(body)뿐이다.

📝 강의 간 연결 "거의 없다"는 정상 상태 이야기다. 폐렴처럼 저산소혈증이 있으면 말초 화학수용기(대동맥체·경동맥체)가 자극돼 환기 요구↑(약물 p.3). COPD 고농도 산소 시 CO2 저류의 주 기전은 V/Q 불균형이고 hypoxic drive는 마지막 순위이며 출제되지 않는다(COPD p.20 교수).

4-4. 상위중추·전체 경로 (p.34–35)

  • 상위중추(higher center) = 대뇌피질·변연계(limbic system)·시상하부(hypothalamus) → 교뇌 호흡중추에 직접 영향 + 호흡근 직접 조절
  • 입력: CSF 화학수용기 → 연수 / 경동맥·대동맥 부위 화학·압력수용기 → 설인신경(N IX)·미주신경(N X) / 폐 신장수용기 → 미주신경(N X)
  • 출력: DRG·VRG → 척수 → 횡격신경(phrenic nerve) → 횡격막 / 기타 운동신경 → 기타 호흡근
  • p.35 그림 라벨은 화학수용기도 "carotid and aortic sinuses"로 묶어 적었다 → 위치 문제는 p.33 텍스트(체, body) 기준

5. 출생 시 호흡 변화 (p.36)

COPD의 병태생리와 치료

오진경 · 10/12
한눈에 보기
  • 진단은 기관지확장제 투여 후 FEV1/FVC < 0.70 (국내·국제 동일). 40세 이상 + 위험인자/증상이면 폐활량측정법 ★
  • 국내 2024 개정: 가·나·다군 폐지 → 지난 1년 급성악화력으로 고/저위험군. 혈중 호산구가 평가 항목에 추가 ★
  • 약물: LABA+LAMA가 1차, 고위험군 + 호산구 ≥ 300이면 ICS+LABA+LAMA 3제. 치료 중 악화가 생기면 호산구 100·300으로 나눔 ★
  • 급성악화: 목표 SpO2 88–92%, SABA ± SAMA 먼저, 프레드니솔론 40 mg × 5일, 메틸잔틴 IV 비권고, NIV 효과 좋음 ★

1. 정의·역학·위험인자

1-1. 정의 ★

  • 기도·폐포 이상(기관지염, 세기관지염, 폐기종) → 기류제한 → 만성 호흡기 증상(숨참, 기침, 가래). 기류제한은 지속적이고 진행할 수 있음 (p.4)
  • 기류제한 = 소기도 질환 + 폐실질 파괴(폐기종)의 복합 작용 ★ (p.4, 32)
  • 국내는 폐결핵 유병률이 높아 감염(결핵)에 의한 COPD가 임상적으로 중요 (p.4)

📝 보충 2024 개정에서 정의의 원인이 흡연 중심에서 다양한 원인으로 넓어졌고, 원인별 분류인 병인형(etiotype)이 도입됨(전사, 슬라이드엔 없음). 폐기종이나 만성기관지염이 있다고 모두 COPD는 아님.

1-2. 역학 (교수가 짚은 숫자 = 3위 · 12.9%/30% · 2.8%/1.6%)

  • 세계 사망원인 1990년 6위 → 2019년 3위("3위면은 되게 높잖아요"), 연간 약 300만 명 사망. 국내 2015년 7위, 80세 이상 5위 (p.5)
  • 국내 유병률 40세 이상 12.9%, 70세 이상 약 30%("생각보다 많이"). 이유는 높은 흡연율·결핵·대기오염(바이오매스 연소) (p.6)
  • 진단 사각지대: 2015년 진단받은 사람 2.8%, 치료받은 사람 1.6% (p.6)
  • 비용: 2015년 직·간접비용 중 간호비 39%가 가장 큼 (p.5)
  • 조기진단: 일반인 전체 선별검사는 사망률 감소·비용효과 이득 없음 → 40세 이상 + 흡연력 등 위험인자 + 기침·가래·호흡곤란 고위험군을 정도관리된 폐활량측정법으로 진단 (p.6)

1-3. 위험인자 8가지 ★ (p.7)

  1. 유전적 인자: 선천성 알파-1 항트립신 결핍증(AATD), 가족력(추가 연구 필요)
  2. 나이와 성별: 고령, 남성(추가 연구 필요)
  3. 폐 성장 이상 — 세부(p.11·교수 설명): 출생 시 저체중, 소아기 호흡기 감염 → 젊을 때 FEV1 낮음
  4. 외부 유해물질: 흡연, 직업성 분진·화학물질, 실내외 대기오염
  5. 사회경제적 수준: 빈곤
  6. 천식과 기도과민성
  7. 만성기관지염
  8. 호흡기 감염: 국내에서는 결핵 과거력 = 비흡연 COPD의 가장 중요한 인자 ★

🎯 교수 강조 (10/12 01:13:11) 국내 지침의 특징 = 결핵. 정의(01:10:21)·위험인자(01:13:11)·Take home(01:43:07)에서 3번 반복 — "특별히 강조하는 게 결핵이 있는 거고요"

  • FEV1 궤적 (p.8): 급속한 FEV1 감소가 없어도 젊을 때 FEV1이 낮으면(시작점이 낮으면) COPD로 진행할 수 있음 → 고위험군으로 관찰

⚠️ 헷갈림 주의 교수는 그래프 아래쪽 두 선을 모두 "COPD로 간다"고 설명했으나 슬라이드에서 TR2는 'Small lungs but no COPD'. COPD로 가는 선은 TR3(정상 시작 + 급속 감소)과 TR4(작은 폐 → COPD). 시험은 슬라이드 기준. AATD는 '유전적 인자', 폐 성장 이상은 별도 항목.

2. 발병 기전·병태생리

2-1. 발병 기전 (p.9)

  • 담배 연기 같은 만성 자극 → 호흡기계 이상 염증반응. 금연 후에도 염증 지속(교수 설명: 남아 있는 유해물질 때문)
  • 산화 스트레스(대식세포·호중구 활성화, 항산화물질 감소) + 단백분해효소 증가 → 엘라스틴 파괴 → 폐기종
  • 염증세포(대식세포·중성구·림프구)가 말초기도·폐실질·폐혈관에서 증가 + 염증매개물질(화학주성인자·염증성 사이토카인·성장인자) 분비
  • 기관지 주변·사이질 섬유화 → 소기도 장애·폐쇄에 기여 (교수 설명: 섬유화가 기도벽을 두껍게 해 악순환)

2-2. 병태생리·전신 영향 ★ (p.10)

  • 소기도: 만성염증 → 섬유화 → 말초기도 협착
  • 폐실질 파괴(폐기종) → 탄성 감소 → 호기 때 기도가 열려 있지 못함 (교수 설명: 폐포 자리를 공기주머니가 차지해 가스교환 저하)
  • 슬라이드: 기류제한과 폐과다팽창은 심장기능에 영향 (교수 설명: 흉곽내압 상승 → 심박출량 감소)
  • 혈중 염증매개물질 → 동반질환: 허혈성 심질환, 심부전, 골다공증, 빈혈, 당뇨, 대사증후군

3. 진단

3-1. 증상·문진 ★

  • 40세 이상 + 아래 지표 → COPD 의심 → 폐활량측정법. 지표가 많을수록 가능성 ↑ (p.11)
  • 가장 특징적 증상 = 만성 호흡곤란, 운동 시 심해짐(DOE). 기류제한보다 수년 먼저 생길 수 있음. 기침·가래는 있기도 없기도 함
  • 문진 지표: 현재 또는 과거 흡연력, 분진·가스 노출(직업, 취사·난방 연기), COPD 가족력(특히 형제), 소아기 병력(저체중 출생, 호흡기 감염)

🎯 교수 강조 (10/12 01:16:36) 간호정보조사에서 현재 흡연 여부만 묻지 말고 과거 흡연력까지 함께 물어야 고위험군을 찾을 수 있음 — "꼭 과거력까지 같이 물어보셔야 되겠고"

3-4. 폐활량측정법(=폐활량검사, spirometry) ★

  • FVC, FEV1 측정 → 기관지확장제 투여 후 FEV1/FVC < 0.70이면 기류제한 확진 (p.13). 국내·국제 동일, 강의에서 3번 반복
  • 고정값 0.70의 한계: 젊은 성인은 과소진단, 노인은 과진단 (p.13). 논란은 있지만 간단하고 널리 쓰여 유효한 기준으로 받아들여짐

⚠️ 헷갈림 주의 천식은 FEV1/FVC < 0.75~0.80 + 심한 폐기능 변동(가변적 기류제한), COPD는 < 0.70(비가역적 기류제한) (p.32).

5. 약물치료 (안정기)

5-1. 약제 분류 ★ (p.16)

  1. 기관지확장제 = 주된 치료: β2 작용제(=베타작용제), 항콜린제, 메틸잔틴, 병합요법
  2. 스테로이드: ICS, ICS+LABA, 경구 스테로이드
  3. PDE4 억제제: 로플루밀라스트(닥사스) 0.5 mg 정
  4. 생물학적 제제: dupilumab, mepolizumab
  5. 기타: 예방접종·항생제, 점액용해제, 항산화제, 진해제 등

🎯 교수 강조 (10/12 01:22:27) COPD는 비가역적 기류제한이라 1차는 기관지확장제. 천식과 달리 스테로이드 비중은 낮고, 호산구가 높거나 악화를 여러 번 겪은 환자에게 ICS 권장(처음부터 계속 쓰는 것 아님) — "천식에서 스테로이드가 제일 중요하다고 강조를 드렸지만". 단, 안정 시 단계치료의 규칙은 '고위험군 그리고 호산구 ≥ 300'(5-2)

  • 로플루밀라스트(닥사스): 기관지확장제가 아니라 경구 항염 유지요법제. 적응증 = 악화 병력 + 만성기관지염을 동반한 중증 COPD에서 기관지확장제의 부가요법 (p.16). 악화 증상 조절용 아님

⚠️ 헷갈림 주의 PDE4 기전 발언은 전사가 불명확함. 슬라이드 표현 '선택적 PDE-4 억제제'로 기억. [보충] PDE4를 억제하면 cAMP 분해가 줄어(cAMP 증가) 항염 효과.

5-2. 안정 시 단계치료 ★ (p.18)

저위험군 LABA+LAMA LABA+LAMA

  • 처음부터 LABA+LAMA 병용이 1차: 병합요법이 단일요법보다 결과가 좋고 부작용도 적었음(선행연구 종합). 약물 강의 p.11은 「LABA/LAMA 단독 또는 병용」·원인 「부교감 긴장도」로 서술 → COPD 강의 문항은 병용 1차·소기도 질환+폐기종(p.4)

🎯 교수 강조 (10/12 01:28:23) 호산구 300이 COPD 약물치료의 중요한 컷오프. 고위험군 + 호산구 ≥ 300이면 처음부터 ICS 포함 3제 — "호산구가 높은 환자는 ICS가 들어가…추가된다라는 걸로 기억"

5-3. 치료 중 악화가 생겼을 때의 단계치료 ★ (p.19)

위험군 호산구 < 100 100 ≤ 호산구 < 300 호산구 ≥ 300
고위험군 악화 LABA+LAMA ± PDE4i ± 마크롤라이드 ICS+LABA+LAMA ± PDE4i ± 마크롤라이드 ICS+LABA+LAMA + Anti-IL-4R(dupilumab) ± PDE4i ± 마크롤라이드
저위험군 악화 LABA+LAMA ± PDE4i ± 마크롤라이드 (< 300 전체) (같음) ICS+LABA+LAMA

🎯 교수 강조 (10/12 01:29:45) 호산구 < 100에서는 ICS 이득이 거의 없음(대규모 연구). 호산구 수치 하나로 치료가 달라짐 — "호산구 100 미만에서는…효과가 거의 없다라는 걸 기억해 주시면"

⚠️ 헷갈림 주의 p.19는 유지치료 중 악화가 생겼을 때 유지 약제를 바꾸는 후속 단계(교수 설명). 급성악화 당시의 응급 약물치료(p.28: SABA, 프레드니솔론 등)와 다른 개념. 고위험군은 3구간(100·300), 저위험군은 2구간(300).

💡 암기 팁 호산구 숫자: < 100 = ICS 효과 거의 없음 / ICS 문턱 = 안정 시·저위험 악화는 300, 고위험 악화는 100 / 고위험 + 악화 + ≥ 300 = 3제 + dupilumab. 생물학적 제제는 이 한 칸에만 나옴.

6. 비약물치료

6-1. 4가지 축 (p.20)

1) 위험요소 제거(교육, 금연, 직업·대기오염) 2) 호흡재활 3) 산소요법·NIV 4) 수술요법

📝 보충 예방접종(교수 구두): 인플루엔자는 모든 COPD 환자, 폐렴구균은 65세 이상에 권장.

6-2. 산소요법: 목표 SpO2 88–92% ★ (p.20)

  • 급성악화 시 목표 SpO2 88–92% = 가장 안전한 최적점. 근거: Austin et al.(2010) RCT (p.20) — 교수 설명: 이 범위로 맞춘 군이 고농도 산소군보다 사망률이 약 58% 낮음
  • 천식 급성악화 93–95%(천식 p.38)·ARDS 삽관 직후 92~95%(ARDS p.22)보다 낮다는 점에 주의

🎯 교수 강조 (10/12 01:30:20) COPD 급성악화 산소요법에서 반드시 짚을 것은 목표 SpO2 88–92% — "산소요법에서 꼭 짚고 넘어갈 게 목표 산소포화도죠"

📝 보충 고농도 산소 시 CO2 저류 기전(V/Q 불균형 > Haldane 효과 > hypoxic drive)은 "시험 문제 나오진 않아요"라고 함.

6-3. 환자 교육·흡입기 ★ (p.21)

  • 일방적 지식 전달만으로는 자가관리 기술 향상이 부족 → 지속적 관리·감독
  • 교육 주제: 금연, 질병 기본정보·병태생리, 치료, 호흡곤란 감소법, 의료진 방문 시기, 악화 대비 자가치료, 임종 관련 내용(임종 시 치료 방향 결정에 도움)
  • 흡입기 순응도↓ → 증상조절 실패, 악화↑, 삶의 질↓, 사망 위험↑

🎯 교수 강조 (10/12 01:34:10) 흡입기는 교육으로 끝내지 말고 환자가 꾸준히, 제대로 쓰는지 확인하는 것이 중요 — "환자가 진짜 꾸준히 제대로 사용하는지 확인하는 게 중요하다"

7-2. 의미·원인·입원 (p.26–27)

  • 주된 원인 = 기도감염(바이러스·세균, 코로나 포함)
  • '잦은 악화자(frequent exacerbator)': 악화를 겪은 환자는 다음에도 악화되기 쉬움 → 향후 악화를 예측하는 가장 중요한 인자 ★

7-4. 호흡보조요법: 산소 → NIV → 침습적 환기 ★ (p.29–30)

  • CO2 저류가 많아 산소 보조와 함께 NIV·인공호흡기로 환기를 도움. 심한 호흡곤란, 의식 변화, 여러 치료에도 계속 악화되면 빨리 기관삽관
구분 적응증 (슬라이드 원문 기준)
ICU 치료 (p.29) 초기 응급처치에 반응 없는 심한 호흡곤란 / 의식 변화(혼란·기면·혼수) / 산소+NIV에도 PaO2 < 40 mmHg 또는 pH < 7.25 지속·악화 / 침습적 환기 필요 / 승압제 필요

LECTURE 4

천식(Asthma)의 병태생리와 치료

오진경 · 10/12

근거 지침: 2022 대한결핵및호흡기학회 천식진료지침(5차) + GINA 2026 (p.3). GINA Track 1·2는 국내 1안·2안과 같은 것. 표기: ★ 시험 유력 · [중요 슬라이드 N] = 교수가 10/13 따로 배포한 '중요 표시' 7장(13·15·16·28·37·38·39) · (p.N) 배포 강의안 쪽 · (보충 p.N) 보충자료 쪽

한눈에 보기
  • 진단 = 가변적 증상 병력 + 가변적 호기 기류제한의 객관적 확인, 둘 다. 기류제한 = FEV1/FVC <0.75–0.80, 가역성 = FEV1 12% 초과 그리고 200 mL 초과 ★
  • 치료의 중심은 ICS. LABA는 항상 ICS와 함께, SABA도 ICS 없이 단독 치료하지 않음(2안 완화제는 SABA지만 1단계부터 ICS 병용). GINA는 1안(완화제 = 필요시 저용량 ICS-formoterol)을 선호 ★

1. 정의와 병태생리

1-1. 정의 (p.4)

  • 이질적(heterogeneous) 질환이고 대개 만성 기도염증이 특징. 두 요소는 ① 시간과 강도가 변하는 호흡기 증상(천명·호흡곤란·가슴답답함·기침)의 병력, ② 가변적 호기 기류제한. 기류제한은 나중에 고정될 수 있음 (p.4)
  • 기도과민성·기도염증은 흔히 동반되지만 진단에 필수조건도 충분조건도 아님. 주관적 증상과 객관적 기류제한을 모두 확인해야 진단 (p.4)

1-2. 역학·원인 (p.5–8) — 숫자는 가볍게

항목 핵심
역학 세계 약 3억 명, 하루 약 1,000명 사망, 대부분 예방 가능한 죽음. 국내 유병률 3.2–4.7% (p.5)
숙주 가족력(환자의 25–80%) · 비만(발생 1.9–2.3배, 지방조직의 렙틴) · 성별(14세 이전 남아 2배 → 성인은 여자↑) (p.6)
환경 집먼지진드기·바퀴벌레, 감염(위생가설: 출생 초기 감염 노출 → 면역이 비알레르기성 경로로 발달), 직업성(성인 천식의 5–20%), 흡연(ICS·전신 스테로이드 효과 감소), 대기오염, 아스피린·NSAID (p.7–8)

1-3. 아스피린 천식 기전 ★ (p.9)

  • 막 인지질 →(phospholipase A2)→ 아라키돈산 → 두 갈래: COX-1/2 경로 → PGD2·PGF2α(염증성) / PGE2(항염) · 5-LO(lipoxygenase) 경로 → LTA4 → LTC4·D4·E4 류코트리엔(염증성). 약물 p.10: 스테로이드는 그 위 PLA2를 억제
  • 아스피린이 COX를 막음 → 아라키돈산이 5-LO 경로로 몰림 → 류코트리엔↑, PGE2↓ → 그림의 시소가 pro-inflammatory 쪽으로 기울어 기도과민성·염증↑ (p.9)
  • 그래서 류코트리엔 조절제(LTRA)가 아스피린 과민성 천식에 특히 도움 (p.24)

1-4. 기도개형·기도과민성 (p.10–11)

  • 기도개형(airway remodeling): 만성 염증과 함께 생기는 기도 구조 변화. 중증도와 연관되고 비가역적 협착을 남길 수 있음 (p.10)
  • 기도과민성 기전 4가지: ① 평활근 비대·과수축 ② 흥분-수축결합 이상: 정상 기도의 '수축의 최대 편평기(plateau)'가 사라져 끝없이 좁아짐 ③ 기도벽이 두꺼워져 협착 증폭 ④ 민감해진 감각신경이 작은 자극에도 과장된 수축 (p.11)

지표 정의
FVC 노력폐활량 [보충: 최대 흡기 후 힘껏 끝까지 내쉰 양]

RV(잔기량) 최대한 내쉰 상태에서도 폐에 남는 공기 (배포본에서 가려짐, 보충 p.2 공개)

  • ① FEV1/FVC >0.75–0.80 = 건강한 성인. 이보다 낮으면 호기 기류제한 (2022 국내) (p.13, 보충 p.2)

  • ③ 슬라이드 라벨은 "FVC의 백분율(%)" = 교수 설명상 정상 예측치 대비 %(%Ref). 정상치가 성별·나이·인종·신장에 따라 달라 예측치 대비 위치를 같이 봄 (p.13, 보충 p.2)
  • RV·TLC는 폐활량검사로 측정할 수 없어 폐용적 검사를 따로 함. 제한성 환기장애 확진은 FVC가 아니라 TLC ★ (보충 p.2 구두 보충)

4-2. ACT·행동지침 (p.33–34)

  • ACT = Asthma Control Test(activated clotting time 아님). 환자가 직접 작성, 지난 4주 5문항 × 1–5점, 25점 = 완벽 조절. 교수는 20점 미만이면 조절이 잘 안 되는 것이라 함(전사 '20점 1층'). 컷오프는 슬라이드에 없음 (p.33). [보충] 표준 ACT: ≥20 = 조절, ≤19(=20점 미만) = 잘 조절 안 됨 → 교수 발언을 '20점 미만'으로 읽으면 표준과 일치
  • 행동지침: 녹색(완화제 주 2번 이하) 유지, 운동 후 악화 소견이 있으면 운동 15분 전 완화제 흡입 / 황색(밤에 깸, 완화제 주 3번 이상) 완화제 추가, 호전 없으면 적색 행동 / 적색(말을 못 함, 청색증) 경구 스테로이드 시작 + 즉시 응급실(119). 자가 치료 후 1–2주 안에 진료 (p.34)
  • 부적절한 치료와 악화 시 치료 지연이 사망의 주원인 → 행동지침 교육만으로도 예방 가능한 사망을 줄임

4-3. 악화 정의·사망 위험인자 (p.35–36)

한눈에 보기
  • 정의: 2024 Global Definition = 비삽관(HFNO ≥30 L/min 또는 NIV/CPAP ≥5) · 삽관(PEEP ≥5) · 자원 제한(S/F ≤315만)의 3범주. S/F(SpO2 ≤97%일 때)와 폐초음파를 허용하고, 1주 이내·양측 침윤은 그대로 ★
  • 원인·예방: 직접(폐렴 1위, 흡인 2위) vs 간접(비폐성 패혈증 1위). 배제 진단이라 ARDS mimics를 꼭 확인. 2차 타격(고VT·수액 과부하·P-SILI·수혈/흡인·감염원 조절 지연)은 막을 수 있다 ★

1. 개념과 정의

1-1. ARDS 개념·특징 (p.2–4)

  • 급성 선행 위험인자(감염·패혈증·외상·흡인)가 유발한 급성 미만성 염증성 폐손상. 단일 질병이 아니라 증후군 (p.3)
  • 핵심 기전 = 폐포-모세혈관 장벽 투과성 증가 → ① 비심인성 단백질 풍부 폐부종 ② 계면활성제(=표면활성제, surfactant) 고갈 ③ 중력 의존성 무기폐 (p.3)
특징 (p.4) 내용 원인
가스교환 불응성 저산소혈증 폐내 단락(shunt)
가스교환 고탄산혈증 폐포 사강(dead space)↑ (미세혈전)
역학 폐 유순도(compliance)↓ 환기되는 폐조직(aerated lung)↓
영상 양측성 폐 침윤
  • 개념 모델 업데이트: 임상 양상은 치료 개입(자세·진정·수액·PEEP)에 따라 달라진다 (p.4)
  • 패러다임 전환: 획일적 프로토콜 → 표현형(생물학적·영상학적·생리학적) 기반 맞춤 치료 (p.2)

1-3. 2024 New Global Definition ★ (p.10–13)

  • 위험인자: 폐렴, 폐외 감염(nonpulmonary infection), 외상, 수혈, 화상(burn), 흡인, 쇼크 (p.10). 선행 위험인자가 명확하면 심부전·수액 과부하가 같이 있어도 ARDS 진단 가능 (Berlin보다 넓게) (p.11)
  • Timing 1주 이내(Berlin과 같음). 영상 = 양측 침윤을 CXR, CT 또는 숙련자의 폐초음파(LUS: 양측 B-line, 흉막하 경화)로 (p.11)

  • S/F는 SpO2 ≤97%일 때만 유효, 메트헤모글로빈·일산화탄소헤모글로빈혈증 의심 시 산소포화도로 진단하지 않음. 추정 FiO2 = 0.21 + 0.03 × O2 유량(L/min). 측정은 자세·FiO2·유량 변경 후 30분 이상 지나서. 환자는 범주 사이를 이동할 수 있다 (p.10)

3. 병태생리

3-1. 정상 폐포를 건조하게 유지하는 4기둥 (p.23–24)

  • 1형 폐포세포(ATI) = 가스교환 / 2형 폐포세포(ATII, =II형 폐포상피세포) = 계면활성제 분비, 이온 수송, 재생(ATI로 분화)
  • ① 치밀이음부(tight junction)가 누출 차단 ② 당질층(glycocalyx)이 백혈구·혈소판 유착 방지 ③ ENaC + Na⁺/K⁺-ATPase가 Na·Cl을 능동 수송해 물을 간질로 퍼냄 ④ 계면활성제가 호기말 허탈 방지 → ARDS = 4기둥이 동시에 무너짐

3-2. 핵심 병태생리 5가지 ★ (p.25–29)

기전 핵심 임상 의미
① 상피 손상 TJ 파괴·glycocalyx 탈락 → 손상 상피가 염증의 능동 주체(호중구 유입 가속) → 괴사 → alveolar flooding, 유리질막(hyaline membrane) 가스교환 차단
② 폐포액 제거(AFC) 장애 사이토카인·ROS·저산소증·고탄산혈증이 ENaC·Na⁺/K⁺-ATPase 억제, ATP 고갈 AFC 저하 = 기계환기 기간↑·사망률↑
③ 계면활성제 이상 양적(ATII 손상으로 생산↓) + 질적(혈장 단백·phospholipase·ROS가 불활성화) 표면장력↑ → 호기말 허탈·중력 의존성 무기폐 → atelectrauma 취약
④ 내피·glycocalyx 손상 세포 간 틈, VE-cadherin 파괴, Ang-2가 Tie2 길항, glycocalyx 탈락 투과성 폐부종
⑤ 염증·면역혈전 TNF-α·IL-1β·IL-6·IL-8 폭발, 호중구 ROS·NETs / tissue factor·PAI-1↑ → 미세혈전 PVR↑, 폐포 사강↑ → 고탄산혈증, 우심실 부담

⚠️ 헷갈림 주의 정수압성 부종(심부전: 장벽은 정상, 압력↑) vs 투과성 부종(ARDS: 장벽이 망가져 정상 좌심방압에서도 샘). ARDS는 같은 수액량에도 부종이 훨씬 심해진다 → 혈역학이 안정되면 보존적 수액 (p.28)

📝 보충 성인 ARDS에서 외부 계면활성제 투여 시험은 모두 실패했다(삼출액이 즉시 불활성화) → PEEP으로 받치고 복와위로 무게를 분산한다(p.27 노트). 교수는 ARDS가 저산소혈증뿐 아니라 면역혈전 때문에 심한 고탄산혈증도 일으킨다고 반복했다.

3-3. 시기별 진행 (p.30–31)

시기 시점 특징
삼출기(exudative) 첫 24~72시간에 시작, ~7일 부종·유리질막·호중구, shunt·유순도 급감. PEEP·복와위 모집 반응이 후기보다 훨씬 좋음 ★

  • 교수: 3단계를 엄격히 나눠 치료하지는 않는다(섬유화는 첫날부터 염증과 동시 진행 가능, 연구로 확인)

📝 보충 발표자 노트: 스테로이드는 초기 삼출기(24~72시간 내, 늦어도 7일 이내)에 써야 효과가 있고, 섬유화기(14일 이후)에 새로 시작하면 효과 없이 신경근병증·감염 위험만 커진다 (p.30–31).

3-4. 침상 생리 — Baby lung·shunt·사강 (slide 32–34)

⚠️ 헷갈림 주의 출제 범위 불명확(맨 위 참고) → 세부 기전은 가볍게, 결론(baby lung = 작은 폐, 1차 기전 = shunt)은 외운다.

  • Baby lung: CT에서 등쪽은 경화·무기폐, 배쪽만 환기 → 남은 폐 = 5~6세 아이 크기(성인의 20~30%). baby lung 자체 유순도는 거의 정상 → "딱딱한 폐"가 아니라 "작은 폐" → 저VT·ΔP 제한의 근거
  • 저산소혈증 1차 기전 = 우→좌 폐내 shunt(V/Q = 0)(>30%면 FiO2 100%에도 불응), 2차 = low V/Q + 저산소성 폐혈관수축(HPV) 소실(혈류가 등쪽 무기폐로 계속 몰려 shunt 악화) (p.33). 고탄산혈증 = 사강↑(미세혈전, 과팽창, 저VT 때 고정 사강 약 150 mL의 비중↑) → ETCO2로 감시

🎯 교수 강조 (10/19 00:37:34) Gattinoni의 Baby lung 개념을 알아야 한다 — "베이비 렁이라는 개념이 중요합니다 … 좀 아셔야 되는데"

🎯 교수 강조 (10/19 00:39:20) ARDS 저산소혈증의 1차 기전은 shunt, 2차는 low V/Q mismatch — "하이폭세미아 기전은 1차적으로 제일 중요한 것은 션트"

🎯 교수 강조 (10/19 00:41:48) 저VT 환기에서는 고정 사강의 비중이 커지므로 ETCO2·Ventilatory ratio로 감시한다 — "이런 것들은 생각하면서 치료하는 게 중요하고"

4. 이질성과 표현형 ★ (p.35–39)

  • 예후를 개선한 건 생리적 지지요법뿐: 저VT(ARMA), 복와위(PROSEVA), 수액(FACTT) (p.35)
  • 모든 ARDS를 한 집단으로 묶은 약물 시험(statin, β2-agonist, iNO, surfactant)·PEEP 연구는 대부분 실패 → P/F <150만 모은 PROSEVA가 복와위 연구 첫 positive
  • 치료 효과의 이질성(HTE): 같은 치료가 한 표현형엔 이득, 다른 표현형엔 해 → 평균 0. 예: simvastatin(HARP-2)은 전체에선 실패, 과염증형에선 생존↑ (p.36, 38)

🎯 교수 강조 (10/19 00:42:16) ARDS 환자는 동질적이지 않으며(heterogeneity), 한 집단으로 묶은 연구는 대부분 실패했다 — "중요한 것은 환자들은 동질한 사람들이 아니다, 헤테로지니어티"

비율 약 30% 약 70%

🎯 교수 강조 (10/19 00:44:45) 대표적으로 알아야 할 것은 과염증형(약 30%, 쇼크·승압제·대사성 산증으로 사망↑)과 저염증형 — "대표적으로 알아야 될 것은 하이퍼인플라마토리랑 하이포인플라마토리"

  • 표현형은 역동적(dynamic heterogeneity): 시기·치료에 따라 매일 바뀜(연구에서 25~50%가 바뀜) (p.39)
  • Treatable traits 4축: 원인/미생물(가역 원인·mimics) · 생물학적(hyper vs hypo) · 역학(high vs low recruitability) · 혈관(우심실 부전, 높은 사강) (p.39)

🎯 교수 강조 (10/19 00:46:41) 표현형은 고정되지 않고 치료에 따라 바뀐다 — "역동적으로 환자가 변할 수가 있다는 것을 알아두시는 게 좋고"

🎯 교수 강조 (10/19 00:46:52) 변화에 맞춰 치료 가능한 특성(treatable traits)을 찾아낸다 — "환자의 치료 가능한 특성을 잘 찾아내는 것이 중요합니다"

🎯 교수 강조 (10/19 00:46:58) 표현형 분류의 핵심 둘 = ① 생물학적 과염증형 vs 저염증형 ② PEEP에 모집되는(recruitable) 환자인지 — "중요한 것은 … 하이퍼냐 하이포냐 … 리크루터블 환자냐 아니냐"

📝 보충 교수: 과염증형에서 높은 PEEP이 더 효과적이었다(슬라이드는 "반응이 다르다"까지). 노트: rosuvastatin(SAILS)은 표현형으로 나눠도 효과 없음.

5. 삽관 전 호흡 보조 ★ (p.40–45)

5-1. 득실과 적시 삽관 (p.40)

  • HFNO·NIV·awake prone: 산소화↑·호흡일↓ → 삽관 위험↓
  • 양날의 검: ① P-SILI(강한 흡기 노력 → 흉막압 음압↑ → 실제 폐에 걸리는 압력↑ → 폐손상) ② 삽관 지연 → 사망률↑. p.43–45 부제가 모두 "Preventing Delayed Intubation"

🎯 교수 강조 (10/19 00:59:58) HFNO·NIV 실패 때 삽관이 늦어지면 P-SILI로 사망률이 오르므로 삽관 시점을 잘 잡아야 한다 — "인투베이션 하는 시점을 잘 잡는 것이… 하나의 중요한 요소"

5-2. HFNO와 awake prone (p.41–42)

  • HFNO: 기도압(PEEP 효과)↑·FiO2 유지 → PaO2↑ = 높은 유량에서 최적 / 사강 세척(CO2 제거)은 낮은 유량에서도 됨
  • 교수 실무: 저산소혈증엔 60 L/min으로 시작(최소 40~60), 이탈 땐 FiO2를 먼저 낮추고 유량은 유지. 20~30 L/min은 사강 세척 정도
  • Awake prone(APP): 하루 8~12시간 이상 → 28일 삽관율 17% vs 27%. 여러 세션으로 나눠도 됨

5-3. ROX index (HFNO) (p.43)

  • ROX = (SpO2/FiO2) ÷ RR, 높을수록 좋음. ≥4.88이면 기계환기 없이 유지될 가능성↑
시점 삽관 고려 지원 강화 후 30분 재평가 계속 관찰
2시간 <2.85 2.85–4.87 ≥4.88
6시간 <3.47 3.47–4.87 ≥4.88
12시간 <3.85 3.85–4.87 ≥4.88
  • 중간 구간은 지원을 강화하고 30분 뒤 ΔROX를 본다 → <0.5면 삽관 고려, ≥0.5면 계속 관찰 (p.43 흐름도)

🎯 교수 강조 (10/19 01:03:39) 힘들게 숨쉬는지·보조호흡근을 쓰는지 눈으로 보는 것도 중요하고, 객관적 지표로 ROX를 쓴다 — "눈대중으로… 보조호흡근 쓰는지 보는 것도 굉장히 중요하지만"

🎯 교수 강조 (10/19 01:04:27) ROX는 한 시점이 아니라 2·6·12시간 추이로 보고 삽관을 판단한다 — "2시간, 6시간, 12시간… 흘러가는지 보는 것도 하나 중요한 요소"

⚠️ 헷갈림 주의 교수는 "4.8"이라고 했지만 슬라이드는 4.88. 점수는 판단 보조 도구일 뿐, 떨어지는 추세면 cutoff 아래로 갈 때까지 기다리지 않고 삽관한다(교수).

5-4. NIV: HACOR와 Vte (p.44–45)

  • HACOR = Heart rate, Acidosis(pH), Consciousness(GCS), Oxygenation(P/F), Respiratory rate. NIV 1시간째 >5점 → NIV 실패 위험↑(AUC 0.89). 활력징후가 멀쩡해도 P/F 101–125(5점) + RR 31–35(1점) = 6점
  • Vte(호기 일회호흡량): NIV 첫 4시간 평균 ≥9.5 mL/kg → 실패율 약 75%(<9.5는 약 20%)

🎯 교수 강조 (10/19 01:06:04) HACOR(HR·pH·GCS·P/F·RR)는 NIV 1시간째 5점을 넘으면 실패 위험이 높으니 봐야 할 지표로 알아 둔다 — "이런 것들이 중요하다는… 봐야 될 지표들이다라는 걸 알아두시면"

🎯 교수 강조 (10/19 01:07:05) 낮은 압력보조에도 Vte가 크게(≥9.5 mL/kg) 나오면 NIV를 끌지 말고 빨리 삽관·진정해 호흡근을 쉬게 한다 — "빨리 인투베이션 하고 세데이션… 1번 전략… 잘 확인하는 것이 중요"

💡 암기 팁 ROX는 높을수록 좋고(≥4.88), HACOR는 낮을수록 좋다(>5 위험). ROX = HFNO용, HACOR·Vte = NIV용.

6. 인공호흡 중 폐손상: VILI·P-SILI·구동압

6-1. VILI 기전 (p.46)

  • 연표: Barotrauma(1973) → Volutrauma(1988) → Atelectrauma·Biotrauma(1997) → Ergotrauma(2016)
  • 4대 기전(슬라이드 빨간 박스) = 압력손상(barotrauma) · 용적손상(volutrauma) · 무기폐손상(atelectrauma: 반복적 열림·닫힘) · 생물손상(biotrauma: IL-8 등 매개체가 순환으로 → 다장기부전). Ergotrauma = mechanical power(전달 에너지)에 의한 손상

⚠️ 헷갈림 주의 교수는 말로 "baro·volu·atelec·ergo"를 나열하고 bio를 따로 설명했지만, 슬라이드의 4대 기전 박스는 Baro·Volu·Atelec·Bio(시험 기준).

🎯 교수 강조 (10/19 01:08:21) VILI 손상은 폐에 그치지 않고 사이토카인을 거쳐 다장기부전까지 가므로 이 요소들을 조절하며 인공호흡기를 유지한다 — "멀티 올간 failure가 올 수가… 잘 조절하면서 벤틀레이터를 유지하는 게 중요"

🎯 교수 강조 (10/19 01:16:45) 인공호흡기는 치료 기계가 아니라 원인 치료(예: 항생제)가 들을 때까지 버티게 하는 지지 수단이므로, 좋아지면 빨리 weaning한다 — "빨리 환자가 좋아지면 위닝도 하는 것이 중요하다"

6-2. 폐 압력·mechanical power (slide 47–52, 57–59)

⚠️ 헷갈림 주의 '생리 출제 안 함'에 가장 가까운 구간(범위 불명확) → 계산은 가볍게, 결론(ΔP 영향이 RR의 4배 → PaCO2를 뺄 때 RR 먼저)은 외운다.

  • Pplat = 흡기말 정지 때 압력(과팽창 지표), 저항압 = PIP − Pplat(≥10이면 가래로 인한 튜브 막힘 의심). 경폐압(PL) = Palv − Ppl(≈식도내압)이 실제 폐를 망가뜨리는 압력
  • E 그림: 환자가 세게 들이쉬면 Pplat이 낮아도 PL이 높다(Pplat 10 + 흉막압 −15 → PL 25) / C 그림: 흉벽이 뻣뻣하면(고도비만·복수·흉수) Pplat 30이어도 흉막압 25 → PL 5 → VILI 위험이 낮을 수 있다 = Pplat 해석의 한계 (p.51 노트)
  • 흉막압은 식도내압을 재야 아는데 루틴으로 재지 않아 환자의 흡기 노력을 직접 알 수 없다 → drive·effort를 관찰해야 하는 이유(교수)
  • Mechanical power = 단위 시간당 폐에 가해지는 에너지(연구용). Costa 2021(slide 59): 단일 환기 변수(VT·PEEP·Pplat·ΔP·RR) 중 사망과 유의하게 관련된 것은 ΔP(OR 1.31)와 RR(OR 1.15)뿐(총 Power·탄성 동적 성분도 유의). ΔP의 영향이 약 4배([4×ΔP + RR]). 사망 위험은 RR ≥25회/분, ΔP ≥15 cmH2O부터 증가

🎯 교수 강조 (10/19 01:08:37) 인공호흡기를 이해하는 핵심은 압력(Paw, Palv, Pplat, Ppl, 저항압)이다 — "벤틀레이터를 이해할 때 중요한 게 pressure입니다"

🎯 교수 강조 (10/19 01:15:27) 경폐압은 침상에서 직접 못 재므로 환자의 호흡 drive·effort를 적당한 선에서 유지한다 — "드라이브나 이포트를 어떻게 적당한 선에서 유지하는지가 중요합니다"

🎯 교수 강조 (10/19 01:23:20) ΔP 1의 사망 영향이 RR 1의 약 4배이므로, PaCO2를 빼려고 분당환기량을 늘릴 때는 ΔP보다 RR을 먼저 올린다 — "RR을 먼저 올리는 게 롱 인저리 측면에서… 더 중요해서"

6-3. 해악을 줄이는 2대 전략과 P-SILI ★ (p.60–63)

2대 전략 (p.60) 방법
① mechanical power 최소화 VT·ΔP·RR↓, NMBA, ECMO
② 폐 불균질성(inhomogeneity) 최소화 적절한 PEEP, 복와위

6-4. 구동압 목표와 근거 (p.53–56)

  • 구동압(ΔP)은 PBW 기준 VT와 달리 기능적 폐 크기(baby lung)와 유순도까지 반영
  • 근거: Amato 2015 NEJM(9개 RCT, 약 3,500명) — 사망은 PEEP이나 Pplat이 아니라 ΔP에 따라 변함. ΔP >15 cmH2O면 병원 사망↑(ΔP 7 증가 → 60일 사망 RR 1.41). 수술 환자에서도 ΔP가 오르면 수술 후 폐합병증↑
Amato 세 시나리오 (p.55 빨간 박스, 교수 01:18:18) 사망
A. PEEP 고정 + ΔP↑(Pplat↑) ↑
B. ΔP 동일 + PEEP·Pplat 같이↑ 차이 없음 → "높은 Pplat이 항상 위험한 건 아니다" / "높은 PEEP이 항상 보호적인 건 아니다"
C. Pplat 고정 + PEEP↑(ΔP↓) ↓
  • 위험 기준: ΔP >15(Amato 노트)·≥15(Costa 노트) → 15 미만 유지가 실무 목표. 교수: 위험이 12부터 가파르게 오르므로 약 12 이하면 충분, 나머지는 RR로 조절

🎯 교수 강조 (10/19 01:16:51) 구동압(ΔP = Pplat − PEEP)은 침상에서 보는 가장 중요한 압력 중 하나다 — "드라이빙 프레셔는 저희가 보는 것 중에 가장 중요한 프레셔 중에 하나"

⚠️ 헷갈림 주의 ΔP 기준을 묻는 객관식이면 15(노트)를 우선한다(12는 교수의 실무 감각).

7-2. PEEP과 폐포 모집 (p.67–71) ★

  • ART trial(JAMA 2017): 폐포 모집술(RM, 기도압 50까지 올렸다 내림) + 점감식 PEEP 적정군이 저PEEP군보다 사망률↑(HR 1.20). 원인(후속 Letter to the Editor, p.68) = recruitability가 큰 환자는 1/3 이하였고 사망 증가는 주로 recruitability가 거의 없는 환자에서 → 펴질 게 없는 폐에 RM·높은 PEEP → 저혈압·RV 부담·과팽창. 이후 RM은 거의 안 함
  • Gattinoni CT: 저모집성 폐에 높은 PEEP → 폐는 안 펴지고 과팽창·저혈압 / 고모집성 폐 → 등쪽이 열려 산소화↑ (p.70)
가이드라인 (p.69) PEEP 권고
ATS 2024 중등~중증에서 RM 없이 높은 PEEP 제안, 장시간 RM 반대
SSC (슬라이드 표기 2026) 중등~중증에서 높은 PEEP 제안, 점증식 PEEP 적정 반대
ESICM 2023(ARDS 지침) 높은 vs 낮은 PEEP 권고 없음(≠ 약물 p.27–28 ESICM 2025 수액 지침 Q10)
공통 메시지 "맞는 폐에 맞는 PEEP"(the right PEEP for the right lung)
  • 가이드라인의 높은 PEEP = 최소 10 cmH2O 이상(교수)
  • 모집 측정: 산소화(간접), 유순도·ΔP(모집과 과팽창을 구분 못 함), CT(침상 적정 불가, 연구용), 폐초음파(과팽창을 못 봄), EIT = 실시간 부위별 과팽창·허탈, 현재 1차로 사용(교수) (p.71)

🎯 교수 강조 (10/19 01:32:49) PEEP은 recruitability를 측정하는 장비·기법(EIT 등)으로 정한다. ATS·SSC는 P/F ≤200에서 높은 PEEP(≥10)을 제안, ESICM은 권고하지 않음 — "리크루터빌리티를 측정할 수 있는 장비나 기법을 사용하여서 정하는 것이 중요하다"

8. 복와위(Prone positioning) ★ (p.72–79)

  • SSC 2021 권고 76: 중등~중증 ARDS에서 하루 12시간 넘게 제안. 메타분석: >12시간 사망↓(RR 0.74), <12시간은 효과 없음 (p.72)
  • PROSEVA(2013): P/F <150 + 하루 최소 16시간 → 복와위 연구 중 처음으로 생존율 개선(이전 연구는 3시간 등 시간 기준 없이 해서 실패) (p.78, 교수)
  • 효과(p.73–77): 앙와위의 배쪽–등쪽 불균질 → 균일화, 등쪽 모집↑(배쪽은 탈모집되지만 등쪽 용적이 더 커서 전체 모집↑), 무기폐·과팽창 모두↓, atelectrauma↓, 사강↓ → V/Q matching↑
  • 대상: 중증 ARDS(P/F <150), 초기(가능하면 48시간 이내), 저VT + NMBA와 함께일 때 결과가 가장 좋음 (p.78)
  • 절대 금기 = 불안정 척추 골절 하나뿐. 어제 기관절개·복부 수술·폐이식 등은 상대적 고려사항(베개 등으로 조정, 살리는 게 우선) (교수, p.78)
  • APRONET: 중등증 10.3%, 중증 32.9%만 시행. 안 한 이유 = "저산소증이 충분히 심하지 않다"(전체 64.3%, 교수: 1번 원인) → P/F를 계산하지 않고 FiO2·SpO2만 봄(교수) (p.79)
  • 실무표(p.78, 교수는 금기만 설명): 3~5명, 사전 산소화·위 비우기·흡인, 수영 자세(팔·머리 2~4시간마다 변경), 중단 = 앙와위 4시간 뒤 P/F >150(PEEP <10, FiO2 <0.6)

🎯 교수 강조 (10/19 01:41:12) 복와위는 일찍 할수록 좋고 늦으면 사망률이 오르므로, 적용 대상(중등~중증, P/F 기준)인지 매일 평가한다 — "적절한 대상자인지를 매일매일 평가하는 것이 중요하고"

📝 보충 예(교수): FiO2 0.4, PaO2 60 → SpO2 94%로 괜찮아 보이지만 P/F = 150 → 복와위를 고려할 상황.

⚠️ 헷갈림 주의 시간: SSC 권고 >12시간/일 vs PROSEVA ≥16시간/일 vs awake prone 8~12시간/일. 권고 강도: SSC 2021 = 조건부(suggest), ATS 그림 = 강한 찬성(초록).

9. 신경근차단제(=신경근육차단제, NMBA) (p.80–83)

  • SSC 2021 권고 77: 중등~중증 ARDS에서 지속 주입보다 간헐 볼루스 제안(조건부, 근거 중등도) (p.80)
  • 근거의 대비: 이전 RCT 3개 = NMBA 지속 주입 > 미사용(90일 사망↓) → 최근 ROSE trial(1,006명) = 48시간 지속 주입 vs 필요 시 볼루스 → 사망률 차이 없음. 즉 "쓰냐 마냐"가 아니라 "지속이냐 간헐이냐"의 문제(쓰지 말자는 뜻 아님, 교수)
  • 같은 슬라이드 회색 박스(약한 권고, 출처 표기 'Ventilation "COVID-19" guidelines CCM 2021'): 지속적 비동조(=비동시성)·깊은 진정 지속 필요·복와위·지속적으로 높은 Pplat이면 지속 주입(CIV) 최대 48시간 — 대부분 환자가 이 예외에 해당(교수). 교수 실무: 초기 ARDS 48시간은 CIV
  • 대표 부작용 = ICU 획득 근력약화(ICU-AW, =ICU 획득 쇠약): 슬라이드는 NMBA가 늘릴 수 있다고 하고(p.81, 약물 p.23 RR 1.16), 교수는 주 기전이 부동이라 deep sedation만으로도 생긴다고 함.
  • 결정 흐름도(p.81): 환기 조정(VT 6, Pplat ≤30) → 진정(RASS −4~−5) → P/F ≤150이면 복와위 → 그래도 보호 환기 불가·높은 drive, 또는 P/F ≤120 → NMBA 권고
  • Rapid practice guideline(p.83): 경증 ARDS = NMBA 주입 반대. 중등~중증 = 얕은 진정으로 보호 환기 가능? → 안 되면 신중한 깊은 진정 + 간헐 NMBA → 그래도 안 되면 CIV ≤48시간
  • 실무표(p.82, 교수는 BIS만 언급): cisatracurium(Nimbex; 약물 p.25: Hofmann 제거) 37.5 mg/h, TOF(척골 0/4·안면 2/4), 투여 전 RASS −4~−5·BIS 40~60(ICU에선 보험 문제로 어려워 최소한 deep sedation을 확인한 뒤 시작), P/F >150이면 중단, 48시간 이후엔 최소 12시간마다 필요성 재평가, 눈 관리·욕창 예방

🎯 교수 강조 (10/19 01:43:53) deep sedation은 하면서 weakness가 걱정돼 NMBA를 안 쓰는 애매한 치료 대신, 쓸 때는 확실히 쓰고 아니면 light sedation으로 가도록 치료 노선을 분명히 정한다 — "치료 노선을 잘 정해서 치료하는 것이 중요하고"

⚠️ 헷갈림 주의 강의 차이가 아니라 지침 차이. ATS 2024(= 약물 p.19·23)는 두 강의 모두 중증(P/F ≤100, 약물 p.23은 '발생 48시간 이내'까지) NMBA 조건부 제안·근거 낮음(p.91 그림도 같음). 🎯 교수 강조 (10/19 01:47:16) VV-ECMO는 경험 있는 센터에서 해야 하므로 경험 센터가 아니면 전원을 준비한다 — "중요한 것은 익스피리언스 센터가 아니면 전원을 보낼 준비를 해야"

🎯 교수 강조 (10/19 01:48:19) ECMO는 늦게 걸수록 예후가 나쁘므로(삽관~ECMO 지연 = 사망 예측인자) 조기에 선별해 결정한다 — "조기에 환자를 잘 선별해서 결정하는 것이 중요하고"

🎯 교수 강조 (10/19 01:48:41) 초기 ECMO 혈류는 최소 3 L/min, 3~6 L로 건다 — "최소한 3리터 플로우… 3에서 6리터 정도는 거는 게 중요하고"

🎯 교수 강조 (10/19 01:48:59) Sweep gas는 낮게 시작해 조금씩 올리고(PaCO2가 급격히 떨어지면 뇌출혈 위험), FDO2는 1.0에서 시작해 낮춘다 — "조금씩 올려서 목표로 하는 스윕가스를 맞추는 것이 중요하고"

🎯 교수 강조 (10/19 01:49:04) ECMO 중 인공호흡기의 핵심은 폐를 쉬게 하는 것(Pplat <25, PEEP ≥10, 호흡수는 최소한) — "중요한 것은 폐를 쉬게 해준다. 벤틸레이터를 과하게 주지 않는다"

⚠️ 헷갈림 주의 Pplat 목표: 일반 ARDS ≤30 vs ECMO 중 <25. 교수는 ECMO 권고가 "2022년 가이드라인부터" 바뀌었다고 했지만 슬라이드는 SSC 2021 권고 78(Carryover) → 슬라이드 기준.

📝 보충 교수는 bridge to recovery vs bridge to transplantation(폐이식 여부)도 ECMO 결정에 고려한다고 덧붙였다. [보충] 메타분석의 RCT 2개는 CESAR와 EOLIA로 알려져 있다(슬라이드에는 연구명이 없음).

11. ATS 2024 권고 한눈에 + 스테로이드 ★ (p.91)

그림 색 권고 강도 중재 적용 범위
빨강 = 하지 마라 강한 반대 장시간 폐포 모집술(RM)(ART에서 나빴음), 고빈도 진동 환기(HFOV) 전 중증도
노랑 = 해도 된다 조건부 찬성 NMBA, VV-ECMO 중증(P/F <100)
노랑 조건부 찬성 높은 PEEP 중등~중증(P/F ≤200)
노랑 조건부 찬성 전신 코르티코스테로이드 전 중증도
초록 = 하라 강한 찬성 폐보호 환기(VT 6 mL/kg PBW, 범위 4~8 + Pplat ≤30), 복와위(약 P/F ≤150) 생존율이 입증된 것
  • 스테로이드: ATS "전신 스테로이드 사용 제안"(조건부 권고, 근거 중등도). 교수: ARDS·패혈증에서는 주자는 쪽이지만 얼마나(용량) 줄지는 가이드라인이 정해 주지 않는다

💡 암기 팁 초록(하라) = 사망률을 낮춘 둘 "6 mL/kg + 엎드리기". 빨강(하지 마라) = "오래 부풀리기(RM)와 진동(HFOV)".

⚠️ 헷갈림 주의 약물 강의(9/14, p.19·21–22)와 같은 ATS 지침: 스테로이드는 두 강의 모두 조건부 권고·근거 중등도. 그림의 막대는 전 중증도, 투여 시기(초기 삼출기, p.30–31 노트)는 ARDS 강의에만. 약물 강의는 "단일 표준 요법 없음(대한중환자의학회), 고혈당 감시"와 Meduri 2007(methylprednisolone 1 mg/kg/d 1~14일 → 28일까지 감량)을 덧붙였다.

12. PICS와 결론 (p.92–93)

  • PICS 3축: 신체(심한 보행장애, 피로, 근위축) / 인지(기억력 저하, 주의력 결핍) / 정신(우울, 불안, PTSD) + 가족의 심리 후유증 → 조기 재활, 섬망 예방, 퇴원 후 다학제 post-ICU 클리닉 (p.92)
  • 결론(p.93): ① 조기 인지·예방 → ② 병태생리·표현형 → ③ 폐보호 환기(저VT, ΔP 제한, PEEP 개별화, P-SILI 조절) → ④ 보조치료(복와위, NMBA, ECMO, 보존적 수액) → ⑤ 스테로이드·이탈·PICS. 가이드라인 = 뼈대(backbone), 생리 기반 개별화 = 핵심, 최소 24시간마다 재평가

💡 암기 팁 PICS = "몸·머리·마음 + 가족".
